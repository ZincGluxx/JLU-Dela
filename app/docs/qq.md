# QQ 群聊（实验）

在 Dela 侧栏打开「QQ 群聊」，连接后用手机 QQ 扫码，勾选要接入的群。无需手动安装 NapCat 或 notice-hub；本机需要已有 QQ。Dela 按需下载固定版本的组件并校验，在自己的数据目录中管理运行副本和登录数据，不修改原 QQ。

可以查看近期可用消息、发送文本和引用回复、下载消息中的群文件、将消息转为个人待办，也可以在工作台打开群聊标签。图片、语音、视频和合并转发暂显示类型占位。

AI 总结先进入现有会话的草稿，用户检查并发送后才交给所选模型。附件只传文件名，不代表读取过正文。转待办保留原文、群名、发送者、发送时间和消息 ID，同一消息不会重复建项。

## 使用边界

- 非官方 QQ 接入依赖客户端版本；同一账号可能退出其他电脑端 QQ。休眠或断开期间不保证收全消息。
- 刷新最多读取 100 条可用记录，界面展示最近 200 条本机缓存，不代表完整聊天历史。
- macOS 已验证独立运行副本可以取得二维码。真实账号收发和 Windows 启动仍需实机验收。
- NapCat 有非商用许可限制，见[上游许可](https://github.com/NapNeko/NapCatQQ/blob/v4.18.42/LICENSE)。运行目录中保留来源与许可说明。

## 验证

`pnpm smoke:qq` 使用合成数据验证界面、IPC、实时消息、回复、文件、待办和 AI 草稿，不登录真实账号。`pnpm probe:qq` 在临时目录准备本机 QQ 的副本，取得二维码后停止并清理；不会登录账号。
