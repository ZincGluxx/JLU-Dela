# 界面沿用

当前计划要求前端先保持原设计，继续使用 Flutter 既有应用壳、主题及组件。新页面在原有层级中接入，公共导航变更与 A 协调，不另建侧栏、全局主题或整套设计系统。

仓库已有[桌面应用壳参考](../client/app-shell-desktop.png)和[窄屏应用壳参考](../client/app-shell-mobile.png)。它们只说明界面方向，不代表对应平台或业务已完成。

分别表达应用账号、学生验证、学院信息、来源连接、加载及同步状态。账号方案见[完整计划](../sources/开发完整内容.md)；学生未验证、学院缺失及依赖不可用时如实提示，保留本地内容及编辑草稿。

各业务负责人实现自己的页面；公共组件确有不足时提出最小改动，与 A 和消费者对齐。按实际交付平台检查窗口缩放、文字可读性、滚动和导航遮挡，不扩展全平台承诺。
