# E：接口与依赖

## 消费的公共能力

| 提供者 | 能力                                             | 使用要求                                                    |
| ------ | ------------------------------------------------ | ----------------------------------------------------------- |
| A      | 当前用户、来源公共层、安全凭据存储及必要文件能力 | 应用身份与邮箱/网课登录分别管理，账号切换清理本模块内存状态 |
| B      | 课程身份及学期                                   | 通过标识关联回放和笔记，不以同名认定同一课程                |
| A      | 个人备份同步                                     | E 定义笔记内容及版本，A 负责授权、传输和公共恢复机制        |
| 主开发 | 自有模型协议、运行地址和必要配置                 | 未提供时实现最小边界与隔离测试，不编造正常生成结果          |

## E 提供的最小语义

笔记应说明归属用户、课程、回放、文本和相关时间位置；时间单位在接口中明确。回放标识和显示名分开，来源失效不删除私人笔记。

邮箱应区分服务端邮件标识、本地缓存和草稿，说明发送结果及附件访问行为。具体字段按协议与实际实现确定，不能用任意本地 ID 冒充跨文件夹或跨设备稳定 ID。

摘要说明输入来源与范围、生成状态和输出，不能将部分片段结果标为整堂课摘要。未接入模型时返回明确不可用状态，而非正常业务中的示例摘要。

## 协作与存储

邮箱凭据只在必要的安全边界使用，不设计默认上传学校密码的邮件代理。是否存在服务端邮件处理需求需另行说明，沿用当前本地优先原则。

笔记备份与邮件服务器同步分开，默认不把附件缓存和全部邮件塞入公共备份。若需新增范围，与 A 明确授权及用途。

## 缺依赖时

没有实际邮箱配置时可测试本地草稿、发送状态和模拟协议，但不能声称真实收发已验证。没有网课权限时可完成笔记、时间关联和页面测试。没有模型时先完成其最小接口约定，继续邮箱和笔记，不等待全部外部条件。
