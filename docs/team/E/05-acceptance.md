# E：测试与验收

## 邮箱

- 连接、读取列表正文、发送、回复转发及附件处理。
- 草稿重开保留，发送失败保留编辑内容和附件选择。
- 网络失败、认证失败及附件不可用有明确状态，不伪造已发送。
- 账号切换不显示上一用户邮件、草稿或凭据。
- 真实发送使用授权测试邮箱和指定测试收件人；本任务书不授权联系其他人。

## 网课与笔记

- 按学期课程打开有权访问的回放。
- 笔记保存后重开仍关联同一课程和回放，可返回对应时间位置。
- 回放或字幕缺失时有真实提示，不删除已有笔记。
- 本地与已启用备份的结果分别验证；冲突不静默覆盖用户记录。

## AI 摘要

- 仅选择的输入进入调用，输出与笔记分开。
- 生成失败或模型未接入时基础笔记仍可用。
- 片段输入范围有说明，模拟输出只在测试中出现。
- 模型尚未提供时，登记接口及测试完成，不登记真实生成已通过。

## 检查

Dart 格式、Flutter 分析与相关存储、状态和页面测试。涉及 Rust 或 OpenAPI 时执行对应格式、Clippy、隔离数据库测试及 `npm run verify`。

媒体播放、附件和系统凭据涉及原生交互，需要在实际目标平台手工验证，注明未覆盖的平台。不得用旧 Electron 验收代替新版。

按 [08-handoff-template.md](08-handoff-template.md) 分别记录邮箱、网课笔记、摘要和备份的结果、样例来源及外部条件。
