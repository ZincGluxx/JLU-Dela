# D：测试与验收

## 多人社区

- 两个实际应用测试账号通过服务端发帖、查看、评论及回复，不以单客户端内存示例替代。
- 作者只能编辑删除自己内容；管理操作按实际管理权限执行。
- 未登录、学生未验证、学院缺失、同学院和不同学院分别测试可见范围。
- 资料引用、图片及直接文件访问不会绕过原权限。
- 点赞收藏、回复通知及个人列表在重载后保留服务端结果。
- 举报可以提交和处理，用户能看到应有处理状态。
- 发帖失败保留草稿；账号切换不显示上一用户草稿或收藏。

## 地图与公共内容

地点查找、校区区分、建筑及房间说明对应；教师位置明确为办公地点。公共更新带来源和时间，失败保留缓存。

三维地图单独验证真实资源加载和地点对应。只有地点列表或二维展示时明确记录三维未完成。

## 检查与交付

执行相关 Flutter 格式、分析、页面与状态测试；Rust 格式、Clippy 及隔离数据库中的权限和持久化测试；契约变更执行 `npm run verify`。

在实际目标平台验证发帖回复及地图操作；记录是否使用真实地图源、文件服务及身份实现。数据夹具中不含真实学生信息。

按 [08-handoff-template.md](08-handoff-template.md) 记录社区和地图各自的交付，不将其中一个完成写成全部完成。
