# D：职责及文件边界

## 主责范围

社区和地图相关 Flutter 功能、Rust 业务模块、业务迁移、OpenAPI 及测试。先确认现有目录和路由，不因还没有目录就预建空模块。旧 `app/` 社区及地点代码仅供行为参考，真实多人服务不能沿用本机示例假定。

## 成员边界

| 成员 | 边界                                                                                |
| ---- | ----------------------------------------------------------------------------------- |
| A    | 提供身份学院结果、公共文件、应用壳及基础设施。D 自己实现社区与地点业务 API 和权限。 |
| B    | 提供课程及资料引用，资料文件不复制成帖子附件以绕过权限。                            |
| C    | 平台作业及资料读取归 C，不抓平台内容自动发帖。                                      |
| E    | 邮件、网课、笔记和摘要归 E，不未经用户明确发布就导入社区。                          |

社区互动通知归 D。它只解决本模块回复、评论及处理状态，不扩展系统推送、通用消息中心或跨业务通知平台。

## 权限边界

作者从服务端当前用户取得，编辑删除检查归属；管理操作需要明确的服务端权限，不能让客户端传入管理员身份。管理员资格使用已有公共机制；缺少时与 A 对齐最小方案，不借机建设通用 RBAC。

全校板块按学生资格开放，学院板块按可信学院限定；客户端过滤不代替服务端检查。无学院不推断所属学院。引用资料、详情和文件继续遵守 B 的原始范围。

## 本角色不扩展的范围

不开发私信、即时群聊、关注推荐系统、交易支付、实时人员追踪或校园定位导航引擎。不整体改版，不新增身份认证步骤，不声称官方合作或数据权威性已获得。

公开上线涉及的运营要求由主开发统一确认，开发完成与运营发布分开记录，本包不授予对外发布权限。
