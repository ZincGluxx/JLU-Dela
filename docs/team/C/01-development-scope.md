# C：开发内容与交付顺序

你负责学习通、智慧树的来源适配、平台课程与作业流程，承担相关客户端、本地数据、必要服务端、接口和测试。

## 建设内容

- 两个平台分别连接、展示状态并获取本人有权访问的课程。
- 将平台课程与 B 提供的课表课程绑定，保留来源标识及学期。
- 读取资料目录，提供查看、获取及返回来源页面的入口。
- 展示作业、截止时间、来源提交状态和最近获取时间。
- 用户主动跳转到原平台作答和提交，客户端刷新来源结果。
- 课程绑定及个人平台数据在本地保存，后续按用户授权接入 A 的备份能力。

## 先后顺序

1. 盘点已有学习通与公共来源实现，与 B 对齐课程引用，列出智慧树缺失的实际接入材料。
2. 先交付一个平台的课程获取、绑定、作业与原页面访问流程；优先复用已有实现。
3. 接入平台资料目录并与 B 明确共享发布边界。
4. 在同一公共基础上补另一个平台，分别验证状态和错误，不复制整套网络与会话代码。
5. 完成账号切换、断网和来源过期回归，接入已交付的授权备份。

没有真实智慧树字段时先完成其他独立部分，保留未接入状态，不猜接口或伪造成功。
