# C：测试与验收

## 两个平台分别验证

- 连接、取消、失败及重新连接状态。
- 课程列表、同名不同课程、不同学期及与课表绑定解除。
- 资料目录、嵌套目录和需要来源会话的访问入口。
- 作业的无截止、仅日期、精确时刻和相对提示，按实际来源覆盖。
- 平台提交状态展示及打开原平台提交页面。
- 不完整结果不宣称全量，失败保留旧数据及上次成功时间。

## 共同回归

账号切换、来源失效与断网不串用私人数据。手机应用身份与来源连接互不冒充；网络失败不直接将整个应用登出。个人材料不会未经操作自动进入共享库，备份排除凭据。

两个来源分别报告测试情况。一个平台验收通过不能替代另一个；没有真实智慧树来源时明确未验收。

## 检查

Dart 格式、Flutter 静态分析及解析、存储、页面与来源相关测试；修改服务端时增加对应 Rust 检查，修改契约时执行 `npm run verify`。手工验证“课程绑定—作业查看—原页面提交入口”，注明真实来源和设备范围。

使用 [08-handoff-template.md](08-handoff-template.md) 交付来源覆盖、字段、依赖和结果。没有实施真实提交时，只记录入口验证，不声称已验证作业提交成功。
