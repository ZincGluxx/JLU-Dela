# C：职责及文件边界

## 主责范围

现有 `clients/flutter/lib/features/assignments/` 是课程作业实现入口；同时定位平台资料读取、来源策略及相关测试。历史 `features/content/` 中的学习通资料解析部分与 B 明确文件所有权后改动，不因同属资料就让两人重复适配。

平台适配和绑定由 C 主责，公共来源会话、HTTP、应用身份和存储入口由 A 主责。确需增加来源能力时提出最小公共修改，说明真实请求需要，不扩大为通用采集引擎。

## 成员边界

| 成员 | 边界                                                                         |
| ---- | ---------------------------------------------------------------------------- |
| A    | 提供公共会话、来源基础、存储和备份；C 不改手机号登录、报告核验或全局状态机。 |
| B    | 提供课程身份及共享资料服务。C 读取平台个人材料，分享需通过 B 明确发布流程。  |
| D    | 不实现社区帖子、地图或互动通知。                                             |
| E    | 不实现邮箱、学在吉大、个人笔记及摘要。                                       |

## 明确限制

- 不自动答题、代作业、自动提交或绕过原平台操作流程。
- 不按名称直接合并课程，不因同名把不同学期课程混在一起。
- 不把一个平台连接成功视作另一个成功，也不把应用登录视作来源已登录。
- 不扩展所有平台、课程模板和媒体类型的覆盖承诺。
- 来源凭据不作为普通学习数据上传备份，不复制开发者 Cookie 充当新用户登录。
- 不因网络错误清空整套账号或擅自删除其他来源会话。
