# B：测试与验收

## 教务与课程

- 学期、周次、节次、调停课及同名不同课程处理符合来源数据。
- 学业完成内容保留学校计算时间、选择条件和统计含义。
- 刷新失败、部分结果与空结果区别明确，失败不覆盖上次成功数据。
- 不同账号的数据、课程引用和缓存不串用。
- C、D、E 至少一个消费方通过确认后的课程契约完成联调。

## 资料与权限

- 上传或收录后可以浏览元数据并获取对应文件，失败有反馈。
- 未登录、未验证、同学院、其他学院分别验证实际访问行为。
- 学院字段为空不能获得学院限定内容；目录、详情及文件都覆盖。
- D 引用资料时，未获权限用户仍不能通过帖子获取文件。
- 删除或修改可见范围后，业务访问结果保持一致。
- 个人缓存、备份与公开发布分别处理，不能自动公开私人资料。

## 检查

按受影响范围运行 Dart 格式、`flutter analyze`、相关 Flutter 测试；Rust 格式、Clippy 与相关测试；涉及数据库时在隔离 PostgreSQL 测试迁移及权限；契约变更在 `contracts/tools/` 执行 `npm run verify`。

手工验证课表到资料的操作流程，注明平台和真实来源覆盖范围。不能用旧测试数、模拟学校数据或单独截图作为真实完成证据。

交付填写 [08-handoff-template.md](08-handoff-template.md)，明确真实教务、文件服务及学院身份尚未覆盖的部分。
