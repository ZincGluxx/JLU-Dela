## B/C 备份接续

[笔记备份](../local-data.md#个人笔记备份)保持原接口和授权范围。教务数据独立分区，不能伪装为笔记；B 现有“选择范围 → 本机摘要”不等于上传授权。服务端只存规范化所选字段，不接收原始学校响应、账号归属、Cookie、令牌、报告码、文件字节或发布草稿。

`GET/PUT/DELETE /api/v1/personal-backup/teaching` 使用同一个 `WorkbenchApi.apiClient`，生成入口为 `PersonalBackupApi.getTeachingBackup/putTeachingBackup/deleteTeachingBackup`。所有结果 `private, no-store`；GET 空状态为 `{revision:0, deleted:true, payload:null, updated_at:null}`，不创建存储行。调用者来自认证上下文，不接受自报归属，笔记分区不受影响。

PUT 为 `{expected_revision, payload}`，DELETE 为 `{expected_revision}`，两种写入都要求 UUID `Idempotency-Key`。相同请求和键只执行一次；同键不同正文返回 `409 IDEMPOTENCY_CONFLICT`。版本不符为 `409 TEACHING_BACKUP_REVISION_CONFLICT`，`error.current` 提供当前快照，不覆盖双方。成功写入只返回 `{revision, deleted, updated_at}`；幂等回执不保存正文。回执可能对应旧操作，客户端成功后需 GET 核对当前状态，不能把旧回执当作最新云状态。删除只清本分区正文，保留递增版本以拒绝旧端复活。

payload 镜像 B 的导出结构：`format=jlu_dela_teaching_backup`、`format_version=1`、UTC `exported_at_utc`；可选分区为成对的 `timetables/period_times`、`course_preferences`、`academic_completion`。未选择分区省略，不发送 `null`；已选择字段内部原有可空值明确保留 `null`。来源仅 IEDU，课程以来源三元组标识。各层未知字段拒绝；空选择拒绝，成功获取的空课表和空学业方案允许。日期必须真实，时间为 RFC3339；学校计算时间、学分及选择约束保留原字符串含义，不自行推算。

生成器的 optional 数组构造默认值会带空数组；B 从已有导出 JSON 调用 `TeachingBackupPayload.fromJson(exported)`，其 `containsKey` 路径保留未选分区的省略。若手工构造模型，须显式为未选数组传 `const Optional.absent()`，否则服务端会因空选区或不成对字段拒绝，不会替用户猜范围。此处不为单个类型改写全局生成模板，也不手改生成物。

规范化 payload 上限 512 KiB；最多 12 学期，每学期 1000 课程/10000 课次，500 节次目录、2000 课程偏好，20 学业方案、每方案 500 课组。数量上限不是可绕过大小限制的额度；请求仍受现有 JSON 请求体上限约束。字符串按 Unicode 字符计：备注 100，来源 ID/名称/教师/地点及学业 ID 300，校区 100，课次说明 2000，其他学业统计字符串 100。学期遵循既有格式，课次必须引用同学期导出的课程；不按名称补配。

B 恢复时按 `SourceRef(source, source_scope, source_id)` 重建当前账号本地关系，不复制另一设备 UUID；保留来源获取时间和学校计算含义，不把恢复时间当作刚从学校同步成功。云冲突拒绝覆盖并返回当前快照；B 必须先保留本地内容，再显式处理双方。恢复不打开上传，关闭停止后续发送，删除云副本不删除本地。公共端点没有代替客户端取得用户授权；B 接入时须在实际发送前明确确认，持久化原待重试请求，切号后丢弃旧结果。本轮不宣称 B 的本地恢复或多客户端完整验收通过。

C 的课程映射需要同时保留两端来源标识及学期；不能只传 `teaching_course_offering_id` 或 `semester_id` 等设备本地键。现有绑定模型可作为字段盘点依据，但尚无 C 的备份导出/恢复契约。先由 C 明确首批选区、获取时间与无目标课程的处理，再由 A 接公共分区；不因学习通完成就开放智慧树占位类型。
