- 精确截止保留来源完整年月日和时分，按北京时间解释并存 UTC；仅日期仍为 `date_only`，不存虚构精确时刻。

## 数据与权限、备份提案

所有映射只进当前账号本地 SQLite，账号切换不删除磁盘内容，但不显示另一账号的内容；不上传服务器。私人资料目录沿用既有本地受控读取，无共享发布操作。B 尚未提供明确发布及权限流程前，不把读取成功当作公开授权。

拟允许用户逐项选择的备份白名单，**不是已接入 API**：

- 映射：平台、来源范围/课程 ID、教务来源身份、学期、创建/修改时间；目标本地行 ID 仅作本地引用，恢复按来源身份解析。
- 课程偏好：同一来源身份下的备注、保留选择；课程名称/教师/来源学期/获取时间仅作为选定缓存快照。
- 作业缓存：来源课程及作业 ID、标题、平台原始/规范状态、截止类型及对应日期/UTC/相对提示、获取时间、本地已读/忽略时间。
- 资料目录缓存：来源课程和条目 ID、父子关系、名称、类型、来源允许获取标志及获取时间；文件内容不包含在此范围，需单独授权和权限审查。

排除 Cookie、密码、应用令牌、来源会话、报告码、临时或签名 URL、原始私人响应、原平台页面 HTML、下载凭据、设备绝对路径和普通错误原文。备份归属由服务端当前账号决定，不信任客户端自报 owner。后续必须提供默认关闭、具体范围选择、关闭/删除、冲突保留、账号生命周期和恢复验证；本次无授权弹窗、无上传、无恢复调用。
