# 计划使用流程

本指南描述[当前开发计划](sources/开发完整内容.md)的目标流程，不代表全部已交付。旧 Electron 安装包使用[旧版指南](../app/docs/user-guide.md)，公共能力与验收范围见[接入说明](public-integration.md)。

## 账号与平台连接

先使用手机号验证码登录应用账号，再按需在账号设置提交学信网学籍报告在线验证码。手机号负责账号唯一性，同一报告可用于多个手机号账号；手机号登录本身不授予学生或学院资格。

登录后可设置用户名、昵称和密码。新用户名为 6—10 位 ASCII 小写字母或数字，不自动去空格或转小写；新密码为 8—16 个 Unicode 标量值，须含 ASCII 大写、小写和数字。旧账号密码登录保留兼容规则。

真实短信供应商尚未接入。本地开发固定码 `114514` 仅限显式开启的 debug 服务监听 loopback；“本地开发验证码已准备好”不代表短信已发送，生产拒绝该配置。

报告核验仅精确匹配学校“吉林大学”，学院来自报告真实“分院”字段，缺失时不猜测。不处理学生唯一标识、学号、姓名或生日，不限制学籍状态、不自动过期或要求重复核验。结果仅表示曾核验吉林大学学籍报告，不证明实时在读、本人或报告持有人；不保存报告码，也不用它作为学生 ID。

原工作区已完成 Rust 原生请求经报告核验 POST 路由到 `/me` 的真实验收，不使用 shell；最新上游 PR worktree 和其他部署环境仍需单独验证。查询受限或失败应提示原因，不显示核验成功；详细记录见[验收范围](public-integration.md)。

按需分别连接 IEDU、学习通、智慧树、学校邮箱和学在吉大。应用账号与来源平台连接各有状态，来源失败不等于应用退出。

## 学习、社区与保存

目标流程包括课表与学业完成、平台课程绑定、资料和作业查看及原平台提交入口；共享资料按学院权限访问。网课笔记保留课程、回放与时间位置，AI 摘要待模型接入；地图、邮箱和社区按实际版本开放，见[团队分工](team-development.md)。

个人内容本地优先，云端备份须主动授权。主动发布的社区内容、共享资料及地图在线保存，与个人备份分开，未发布草稿不自动公开。凭据、令牌、Cookie 和报告码不进入普通业务备份。
