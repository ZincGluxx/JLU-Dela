## 评审范围

| 接口 | 参数 | 返回 |
| --- | --- | --- |
| `GET /api/v1/semesters` | `limit`、`cursor` | 学期、当前学期证据、快照状态 |
| `GET /api/v1/courses` | 可选 `semester_id`、`source`、`retained`、分页 | 统一课程、各来源快照状态 |
| `GET /api/v1/schedule` | 必填 `semester_id`、`from`、`to`；可选分页 | 已展开为具体日期的课次、范围快照状态 |

机器契约仍只有 [openapi.yaml](../contracts/openapi.yaml)。三个端点均标记为
`design-only`，本草案和生成 SDK 不表示对应服务已上线。

共享课程由 B 提案，与 E 对齐，交 A 总审和人工合并。C 的来源评审与 D 的独立
验收暂无人员，待团队指定后执行；AI 自检不替代这两项评审。本文中的 C/D 均指
待指定的团队角色。真实授权读取、上传确认和并发顺序仍由 A 统一协调。

## 需要确认的设计

| 草案选择 | 需要谁确认 |
| --- | --- |
| 课程列表使用 `meta.source_snapshots`，指定来源时一项，未指定时按 `jlu_iedu`、`chaoxing` 返回两项 | A/C/E |
| `source_scope` 暂用非空字符串，与用户、来源、原始 ID 一起确定映射身份 | A/C；需真实来源证据 |
| 快照 coverage 表示来源采集范围，分页和 retained 筛选不改变该范围 | A/C/E；需和上传协议对齐 |
| 学期按起始日降序、未知排后；课程按名称；课次按开始时间；均追加稳定 ID 升序 | A/C/E |
| 日期参数为上海校园日期，范围左闭右开、最长 93 天；实际课次时间用 UTC | A/E |
| 无来源课次 ID 时的去重键、调停课识别，以及无法解析记录的交付方式 | C/A；本次不猜定 |

草案约定：学校来源授权失效时，已有缓存的 GET 应返回缓存和 `stale` 状态。
401 只表示工作台身份失效。上传/刷新操作的 409 和网络失败 HTTP 映射由 A 的
统一协议另行确定，不在此草案中建立新的上传入口。

## 样例和测试的含义

[teaching fixtures](../contracts/fixtures/teaching/manifest.json) 的 15 个响应均为合成数据，
没有真实账号、课程原文、学校 Cookie 或令牌。它们是合成样例，不是已经取得的
真实脱敏学校样例。日期、作息、教室和来源 ID 均不代表吉林大学规则。

样例覆盖普通课、调课、停课、完整空结果、从未同步、学期起点未知、部分读取失败、
学校授权失效、跨午夜和同名不同来源课程。调课样例仅演示“已确认是同一课次”的
响应变化，不证明已掌握学校的调课识别方式。

客户端契约测试检查生成模型的解析/序列化、空值、来源状态、与 E 的 LessonItem
兼容，以及实际发出的查询参数。它们不证明数据库隔离、同步更新或真实接口已实现。

生成器原模板把日期查询序列化为完整 UTC 时间戳，与 `format: date` 不符。
本次定制标量日期查询的模板，保持输入的年月日并输出 `YYYY-MM-DD`；其余类型不变。
同一修复也作用于日历查询，两处均有最终 HTTP 请求测试。模板取自 OpenAPI Generator
7.27.0，原 Apache-2.0 许可证保留在模板目录；这项公共工具变更交 A 审核。

教学周解析器是独立编写的纯语法工具，本轮未迁入旧工程代码。当前语法是
`1-5,8,10`、`1-16周(单)`、`1-16周(双)`，兼容中文逗号和括号；单双后缀作用于
整个列表。调用者必须提供总周数。未知语法报错，不推测日期、节次或学校默认值。
这项语法仍需用真实来源样例确认，不属于完整学校网页解析器。
